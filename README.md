## Présentation

Plugin du serveur SkyHand.

Utilisé sur : **Opale**.

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shwc` | — | Stocke ou exécute immédiatement une commande pour un joueur selon son monde | `shworldcommands.use` |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `shworldcommands.use` | Permet d’utiliser la commande /shwc | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `commands.yml`
- `config.yml`

## Compilation

Java 25 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
